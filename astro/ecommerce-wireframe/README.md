# eCommerce Wireframe (Wix Stores)

A non-branded wireframe storefront for a general multi-category store, built on Wix Headless (Astro).

**What it shows**
- Home page merchandising: hero, category tiles with hover images, featured rail, sale band, why-us, testimonials
- Shop and category pages: 4-column grid, filters popup (price, options, stock), sort, color swatches on every card
- Product page: gallery, variants and modifiers, related products
- Quick add from any card, cart drawer (Cart V2), hosted Wix checkout
- Search with suggestions, mega menu, mobile nav
- About, Contact (Wix Forms), newsletter signup, CMS-driven legal pages

All copy and images come from the site: products and categories from Wix Stores, page sections, testimonials and legal pages from the Wix CMS, forms from Wix Forms.

**Wix apps:** Wix Stores, Wix eCommerce, Wix Forms, Wix CMS.

## Quick start

```bash
npm install
npm run dev
```

Publish with `npx wix build && npx wix release`.

See [TEMPLATE_GUIDE.md](TEMPLATE_GUIDE.md) for the design system, where each string is managed, and the pre-launch checklist.
